# Q11: ASP.NET Core MVC Project Structure

This is a focused Q11 demo project. It shows the MVC folder structure,
service registration, HTTP request pipeline, conventional routing, terminal
startup, and a local browser page.

## Structure

```text
Q11_ProjectStructure/
├── Controllers/
│   └── HomeController.cs
├── Models/
├── Views/
│   ├── Home/
│   │   └── Index.cshtml
│   ├── _ViewImports.cshtml
│   └── _ViewStart.cshtml
├── wwwroot/
├── Program.cs
└── Q11_ProjectStructure.csproj
```

## Run

```powershell
cd "C:\Users\Admin\Downloads\NCCS_Lab\NCCS_Lab\PartB_AspNetCoreMVC\Q11_ProjectStructure"; dotnet run
```

Open the `localhost` URL displayed in the terminal.
