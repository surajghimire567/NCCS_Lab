NCCS Lab - Changes Compared With Original
==========================================

This file lists the changes made during troubleshooting and demo setup.


1. PartA_CSharp\Q04_GenericStack\Q04_GenericStack.csproj
----------------------------------------------------------------

BEFORE:
- The project used the default .NET SDK file inclusion rules.
- The unrelated nested folder "NCCS_Lab_MV" was included during compilation.
- This caused duplicate Program declarations and Razor/MVC compilation errors.
- Relevant project file:
    <Project Sdk="Microsoft.NET.Sdk">
      ...
    </Project>

AFTER:
- Added exclusions for the nested "NCCS_Lab_MV" folder:
  Compile
  EmbeddedResource
  None
  Content
- Added project file section:
    <ItemGroup>
      <Compile Remove="NCCS_Lab_MV\**" />
      <EmbeddedResource Remove="NCCS_Lab_MV\**" />
      <None Remove="NCCS_Lab_MV\**" />
      <Content Remove="NCCS_Lab_MV\**" />
    </ItemGroup>
- Q04 now compiles only its own generic stack console application files.


2. PartB_AspNetCoreMVC\NCCS_Lab_MVC\Program.cs
------------------------------------------------

BEFORE:
- The production exception-handling block contained stray "S" characters:
    if (!app.Environment.IsDevelopment())
    {S
        app.UseExceptionHandler("/Home/Error");
        app.UseHsts();S
    }
- The project could not compile.
- Razor Pages services and endpoint mapping were not registered.
- A new SQLite database did not automatically receive its schema.
- The Users table required by Q20 was not created.
- Q19 did not automatically create the Admin role or demo Admin account.

AFTER:
- Removed the stray "S" characters.
- Corrected code:
    if (!app.Environment.IsDevelopment())
    {
        app.UseExceptionHandler("/Home/Error");
        app.UseHsts();
    }
- Added:
    builder.Services.AddRazorPages();
- Added database setup:
    using (var scope = app.Services.CreateScope())
    {
        var db = scope.ServiceProvider.GetRequiredService<AppDbContext>();
        db.Database.EnsureCreated();
    }
- Added startup database initialization with:
    db.Database.EnsureCreated();
- Added the Q20 Users table and sample records:
    alice
    bob
- Added the Q19 Admin role.
- Added the Q19 demo account:
    Email: admin@localhost
    Password: Admin123!
- Added the Admin role to that account.
- Added:
    app.MapRazorPages();
- Added endpoint mapping:
    app.MapRazorPages();

6. PartB_AspNetCoreMVC\NCCS_Lab_MVC\Views\Shared\_LoginPartial.cshtml
----------------------------------------------------------------------

BEFORE:
- File did not exist.
- The default ASP.NET Core Identity UI returned a runtime error because the layout
  expected "_LoginPartial".

AFTER:
- Added login/register links for signed-out users.
- Added account and logout links for signed-in users.
- Added code pattern:
    @if (SignInManager.IsSignedIn(User))
    {
        <a asp-area="Identity" asp-page="/Account/Manage/Index">Account</a>
        <form asp-area="Identity" asp-page="/Account/Logout" method="post">

        </form>
    }
    else
    {
        <a asp-area="Identity" asp-page="/Account/Login">Login</a>
    }
- Q19 Identity pages can now render successfully.
